\subsection{Proces vymazání}\label{proces-vymazuxe1nuxed}

Data se odstraňují tak, aby chyba ocenění byla \textless{} 0.15 a aby
strip plot ukazoval pouze přihlehlé hodnoty pro každý titul, za účelem
vyřazení extrémů. Pro každý titul byla data omezena na hodnoty mezi 4\%
a 96\% kvantilem, mimo tituly:

\begin{itemize}
\tightlist
\item
  Měnové indexy (\^{}XD\_), které neomezujeme, jelikož jsou již
  korektní,
\item
  NFLX, pro který je omezení 8\% a 96\%, z důvodu velkého počtu
  extrémních negativních hodnot.
\item
  JNJ a PG, pro které je omezení 6\% a 96\%, ze stejného důvodu.
\end{itemize}

Titul \^{}VIX byl odstraněn kvůli zkreslení modelu kvůli vytváření
samostatných clusterů s extrémy.
